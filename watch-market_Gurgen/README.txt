ԺԱՄԱՊԱՀ — ԺԱՄԱՑՈՒՅՑՆԵՐԻ ԱՌՔ ՈՒ ՎԱՃԱՌՔ

ՏԵՂԱԴՐՈՒՄ XAMPP-ՈՎ
1. ZIP-ը extract արա։ Պետք է ստանաս watch-market պանակը։
2. Պանակը պատճենիր C:\xampp\htdocs\watch-market հասցեում։
3. XAMPP Control Panel-ում Start արա Apache-ն և MySQL-ը։
4. Բրաուզերում բացիր http://localhost/phpmyadmin/
5. Ընտրիր Import (ռուսերեն՝ Импорт), ընտրիր watch-market/database.sql ֆայլը և սեղմիր Go/Вперёд։
   Այլ տարբերակ՝ phpMyAdmin-ում SQL բաժնում բացիր database.sql-ի տեքստը և գործարկիր։
6. Բացիր http://localhost/watch-market/

Եթե կայքը գրում է, որ տվյալների բազայի հետ կապ չկա՝ համոզվիր, որ MySQL-ը միացված է և database.sql-ը ներմուծված է։
Եթե MySQL root-ի համար գաղտնաբառ ես դրել, այն լրացրու config.php-ի $password փոփոխականում։

ԻՆՉ ԿԱ ԿԱՅՔՈՒՄ
- Ժամացույցների կատալոգ
- Որոնում և ֆիլտրեր ըստ բրենդի, տեսակի, սեռի/ոճի, առավելագույն գնի
- Գնի դասավորում
- Գնման հայտ՝ անունով և հեռախոսահամարով
- Ժամացույց վաճառելու հայտի ձև
- Հայտերը պահվում են MySQL տվյալների բազայում

Նշում. սա ուսումնական նախագիծ է։ Առցանց վճարում և ադմինիստրատորի վահանակ ներառված չեն։
