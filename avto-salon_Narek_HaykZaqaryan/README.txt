DRIVE — Ավտոսրահի ուսումնական նախագիծ

Ֆայլեր՝
- index.php: կայքի էջը (HTML/CSS/JavaScript)
- db.php: MySQL կապը
- api.php: մեքենաների ցուցադրում, ավելացում և ջնջում
- database.sql: տվյալների բազայի և օրինակային մեքենաների ստեղծում

Աշխատեցնելու քայլեր (Windows + XAMPP)
1. Տեղադրիր XAMPP-ը։
2. Պանակը avto-salon պատճենիր C:\xampp\htdocs\avto-salon հասցեով։
3. XAMPP Control Panel-ում գործարկիր Apache և MySQL։
4. Բացիր http://localhost/phpmyadmin
5. Ընտրիր Import և ներմուծիր database.sql ֆայլը։
6. Բացիր http://localhost/avto-salon/index.php

Եթե MySQL-ի root օգտատիրոջ մոտ գաղտնաբառ է դրված, փոխիր db.php-ի $password արժեքը։
Նախագիծը ուսումնական/local զարգացման համար է։ Հրապարակային կայքում ավելացրու մուտքի իրավունքների վերահսկում և պաշտպանություն ադմինիստրատիվ գործողությունների համար։
