ATELIER — կայքի տեղադրման ուղեցույց

1. Պատճենեք ամբողջ atelier_shop պանակը PHP և MySQL աջակցող հոսթինգում։ Պահպանեք պանակների կառուցվածքը՝ assets/css/style.css և assets/js/app.js։
2. phpMyAdmin-ում ներմուծեք schema.sql ֆայլը։ Այն ստեղծում է fashion_shop բազան, products, orders և order_items աղյուսակները և ավելացնում է փորձնական ապրանքներ։
3. config.php ֆայլում լրացրեք ձեր MySQL սերվերի հասցեն, բազայի անունը, օգտատիրոջ անունը և գաղտնաբառը։
4. Բացեք index.php-ը ձեր տեղական PHP սերվերով կամ հոսթինգի հասցեով։ Մի բացեք ֆայլը ուղղակիորեն file:// ռեժիմով։
5. Փորձարկեք ապրանքի ընտրությունը, զամբյուղը և պատվերի հաստատումը։ Հաստատված պատվերը պահվում է orders և order_items աղյուսակներում, իսկ ապրանքի մնացորդը նվազեցվում է products աղյուսակում։

Նշում․ զամբյուղի ժամանակավոր պարունակությունը պահվում է այցելուի browser localStorage-ում, իսկ պատվերը և պատվերի ապրանքները գրվում են տվյալների բազա միայն «Confirm order» կոճակը սեղմելուց հետո։ Իրական վաճառքից առաջ ավելացրեք HTTPS, ադմինիստրատորի պաշտպանված էջ, վճարման ինտեգրում և հոսթինգին համապատասխան անվտանգության կարգավորումներ։
